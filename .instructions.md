# TMDB-Import Development Instructions

## Project Overview
TMDB-Import is a Python automation tool for extracting TV series metadata from multiple streaming platforms and importing it into The Movie Database (TMDB). It uses Playwright for browser automation and supports 40+ video platforms.

## Architecture

### Core Modules
- **`tmdb_import/__init__.py`** - Package initialization and public API exports
- **`tmdb_import/__main__.py`** - CLI entry point with argument parsing
- **`tmdb_import/extractor.py`** - Base extractor class and metadata extraction logic
- **`tmdb_import/importor.py`** - TMDB import functionality with browser automation
- **`tmdb_import/processor.py`** - Data processing and image handling
- **`tmdb_import/common.py`** - Shared utilities and constants
- **`tmdb_import/version.py`** - Version information

### Subdirectories
- **`tmdb_import/extractors/`** - Platform-specific metadata extractors (anidb, bilibili, netflix, etc.)
- **`tmdb_import/importors/`** - Platform-specific importers (currently TMDB)
- **`tmdb_import/processors/`** - Data processors (image cropping, format conversion, etc.)
- **`tmdb_import/util/`** - Utility functions and helpers

## Key Concepts

### Metadata Structure
- **`Metadata`** - Show-level data (title, overview, poster, backdrop, language, seasons)
- **`Season`** - Season-level data (season_number, name, episodes)
- **`Episode`** - Episode-level data (episode_number, name, air_date, runtime, overview)

### Extractors
Each platform extractor:
- Extends the base `Extractor` class
- Implements `extract()` method to return `Metadata` object
- Handles platform-specific HTML parsing or API calls
- Returns data in standardized format

### Configuration
- File: `config.ini` in working directory
- Section: `[DEFAULT]`
- Key options: encoding, TMDB credentials, filter settings, image handling

## Development Guidelines

### When Adding a New Platform Extractor
1. Create `extractors/platform_name.py` extending `Extractor`
2. Implement `extract()` method returning `Metadata`
3. Add platform to the extractors registry in `__init__.py`
4. Document in README.md supported features table
5. Handle errors gracefully with try-except blocks

### When Modifying Image Processing
- Changes go in `processors/` directory
- Maintain backward compatibility with existing image formats
- Update configuration options in config.ini documentation if needed

### Dependencies
- **Required**: `python-dateutil` (datetime parsing)
- **Optional**: `playwright` (browser automation), `Pillow` + `bordercrop` (image processing), `opencc-python-reimplemented` (Chinese conversion)
- Dependencies are loaded on-demand with helpful error messages

### Testing
- Test with multiple platforms when possible
- Verify metadata extraction returns complete structure
- Test image processing with various aspect ratios
- Test import workflow with test TMDB account

## File Organization Rules
- Platform extractors: `tmdb_import/extractors/{platform}.py`
- Utilities: `tmdb_import/util/{functionality}.py`
- Keep common logic in `common.py`
- Configuration options documented in README

## Common Tasks

### Adding Configuration Option
1. Add to `config.ini` example in README.md
2. Document in configuration table
3. Load from config in appropriate module using `ConfigParser`

### Supporting New Site
1. Analyze site structure (HTML/API)
2. Create extractor in `extractors/site_name.py`
3. Update README supported sites table
4. Test extraction and TMDB import workflow

### Fixing Browser Issues
- Check Playwright installation: `playwright install chromium`
- Use `--debug` flag for detailed logging
- Verify site hasn't changed its structure
- Consider adding waits for dynamic content

## Code Style
- Follow Python PEP 8 conventions
- Use type hints where appropriate
- Add docstrings for public methods
- Keep functions focused and testable
- Use descriptive variable names

## Documentation
- Keep README.md and README.zh-CN.md in sync
- Update version in `version.py` for releases
- Add inline comments for complex logic
- Document new configuration options immediately
